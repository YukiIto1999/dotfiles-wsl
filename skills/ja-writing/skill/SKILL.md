# 日本語の執筆と推敲

読み手がこの文章を読む場面から考え、内容の選択、構成、表現の順に書き、最後に原資料へ照らす。
短い返信にも使うが、検討の長さは文章に合わせる。求められていなければ、検討過程を添えず完成稿を返す。
事実、文書形式、件名やコメントの規約は担当Skillから引き継ぐ。この手順を一律の文体指定として使わない。
Skillを使える環境では、文書・記事は`description-writing`、差分に基づく変更説明は`change-writing`を内容と形式の担当にする。
担当をまだ読んでいなければ先に読み、既に担当から渡された仕事では読み直さず、同じ原稿の執筆を続ける。

## 1. 何を伝える文章か決める

依頼、素材、直前のやり取りから、書き手と相手の関係、相手が既に知ること、今回伝えることを区別する。
相手が読み終えて判断すること、行うこと、感じ取ることに必要な内容を選ぶ。
執筆者への注意や設定は選択の条件であり、そのまま本文の項目ではない。
原稿の改訂では、直したい不自然さと、残す意味や語り口を先に分ける。
言い回しの欠点を直すときも、その文が担っていた出来事や発話の意図は引き継ぐ。
内容を決められない不足だけを質問し、残してよい曖昧さは残す。

## 2. 読み進められる構成にする

段落ごとに「ここまでで何が分かり、ここで何が加わるか」を考えて並べる。
説明なら問いが解ける順序、手順なら実行できる順序、参照文書なら探せる区分を選ぶ。
随筆や物語では、出来事と知覚、回想、内省のつながりから、その語り手の運び方を作る。
既知の話は必要なところで受けて先へ進み、再説明が要る箇所だけ立ち戻る。
話題の転換や対比、帰結には、受ける内容が分かる接続表現や橋渡しを置く。
関係がつかめなければ、接続詞を足す前に情報の位置と必要性を見直す。

見出しは段落のまとまりに付ける。読者がその節で知ることや探す項目を、前後との違いが分かる名前にする。
親子の範囲や節の重複を確かめ、構成が悪ければ見出しの言い換えで済ませない。
概念名、慣用的な項目名、問い、主張のどれが適切かは節の働きで選ぶ。
短い文章を見出しで細切れにしたり、見出しだけに話題の接続を任せたりしない。

## 3. 書いてから、続けて読む

初稿を数段落ずつ読み、話の飛躍、説明の足踏み、主な話と補足の比重を直す。
次に、主題と述語、修飾、否定、並列の対応を確かめる。
語の結び付きが不自然なら類語に置き換えるだけでなく、誰の何について何を言う文かに戻って組み直す。
用語は一貫させ、文脈で分かる対象は指示や省略でも受ける。語彙の多さ自体を目標にしない。

書き手の声として通して読み、相手との距離、文の長短、言い切り方の変化に理由があるか確かめる。
条件を一息で受ける文と、判断や反応で切る文を意味に合わせて使う。音声では聞いて追えるまとまりにする。
反復、断片、比喩、含みは、その箇所での働きを見て生かす。
軽い推敲では、機能している表現まで自分の好みの文体に替えない。

## 4. 意味を照合して仕上げる

ここでは文章の滑らかさで判断せず、素材と完成稿を照合する。
原稿や資料の出来事、条件、対象、期間、確度、約束が、完成稿でも同じ意味か確かめる。
省いたものは、読者に不要な背景なのか、伝えるべき内容を落としたのかを区別する。
逆に、完成稿で加えた主張や具体化には根拠があるか確かめる。創作の補完は依頼の範囲と視点に従う。
書き手への注意を本文で説明していたら、読者にそれを伝える必要があるか見直す。
意味を直した箇所は前後も読み直し、つながりと語調を整えて返す。
